# Destinations

## WhatsApp
- Good for small CSVs.
- If file is large, upload to Drive and send the link.

## Google Drive
- Preferred for large exports.
- Share link back to user.

## Google Sheets
- Use for ongoing lists a user edits.
- Choose: overwrite tab vs append.

## Bunny Storage
- Use for archiving exports or feeding other tooling.
- Recommend folder naming: `exports/<segment>/<YYYY-MM-DD>/file.csv`.
