- SOP for Apollo temp account via tinyhost:
  1) Open https://tinyhost.shop
  2) Click Generate New Email to get temp inbox; share address with user.
  3) User uses temp email to sign up on Apollo.
  4) Click Check Inbox on tinyhost; open Apollo email.
  5) Open activation link from email.
  6) On Apollo “Set Name & Password” page, fill Full Name + Password (>=10 chars + at least one number), confirm, submit.
  7) Wait for “password reset/redirect” confirmation; proceed if next step appears.
- Defaults used: random full name (e.g., Ava Stone) and strong random password; share password before submitting; submit only on explicit user approval.
- Apollo onboarding SOP after activation:
  1) Go to https://app.apollo.io (or redirected after activation).
  2) Q1 Role: pick random option (e.g., Founder/CEO) unless user specifies.
  3) Q2 Start using: pick one random card (e.g., Find and connect with new leads).
  4) Q3 Goals: pick one random goal (e.g., Find high-quality leads).
  5) Q4 Familiarity: pick random (e.g., I’ve used similar tools).
  6) If email connect step appears, click Skip for now (per user instruction to skip when available).
  7) Land on “Prospect your way with Apollo” page; ask whether to click Start searching.
